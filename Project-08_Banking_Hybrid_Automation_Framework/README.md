# 🏦 Banking Hybrid Automation Framework

Enterprise-level UI Automation Framework built using Selenium WebDriver, Java, TestNG, Maven, and Page Object Model (POM).

## 🚀 Tech Stack

- Java
- Selenium WebDriver
- TestNG
- Maven
- Page Object Model (POM)
- WebDriverManager
- Apache POI
- Extent Reports
- Log4j2
- Git
- GitHub
- GitHub Actions (CI)

---

## 📌 Project Objective

Build a scalable and reusable Hybrid Automation Framework for a Banking Application following industry best practices.

---

## ✨ Features

- Login Automation
- Account Overview Validation
- Fund Transfer Automation
- Bill Payment Automation
- Transaction Verification
- Data-Driven Testing
- Cross Browser Support
- Screenshot on Failure
- Extent HTML Reports
- Logging using Log4j2
- GitHub Actions CI Pipeline
